# Application screenshots

These images capture the actual macOS app using an isolated profile and a fictional **Studio**
workspace (**Студия** in Russian). They show the block editor, a table database, and the same
database in a board view with the dark theme. The app interface and demo content are localized
for each README. The source revision is `9e2bddc`.

The images contain no personal workspace content, credentials, or external media. MCP stays
disabled. They are app-content captures rather than images of the entire desktop.

When replacing them, use fresh `SHECO_DATA_DIR` fixtures, capture the real interface in both
languages, and inspect every image before committing it. Keep matching views and filenames
across the two READMEs. Do not use the persistent design preview for publication screenshots.

PNG assets are stored at 2880 × 1880 pixels (1440 × 940 app content at 2× display scale).
