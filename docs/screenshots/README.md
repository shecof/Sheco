# Application screenshots

These images capture the actual macOS app using an isolated profile and a fictional **Studio**
workspace (**Студия** in Russian). They show the block editor, table and board database views,
a code block with an open range comment, local images and file attachments, and the optional
command builder plugin. Board views use the dark theme; the other views use the light theme.
The app interface and demo content are localized for each README.

The images contain no personal workspace content, credentials, or external media. The sample
illustration and attached Markdown/CSV files were created for this demo. The command target
`192.0.2.1` is illustrative; no command is executed. MCP stays disabled. They are app-content
captures rather than images of the entire desktop.

When replacing them, use fresh `SHECO_DATA_DIR` fixtures, capture the real interface in both
languages, and inspect every image before committing it. Keep matching views and filenames
across the two READMEs. Do not use the persistent design preview for publication screenshots.

PNG assets are stored at 2880 × 1880 pixels (1440 × 940 app content at 2× display scale).
